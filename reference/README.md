# Generals and Zero Hour reference source

Electronic Arts published this source under GPL version 3 with additional terms.
The upstream snapshot is [commit 0a05454d8574207440a5fb15241b98ad0b435590](https://github.com/electronicarts/CnC_Generals_Zero_Hour/tree/0a05454d8574207440a5fb15241b98ad0b435590), dated
2025-02-27. Its [licence](CnC_Generals_Zero_Hour/LICENSE.md) is included unchanged.

Search `GeneralsMD/Code` for Zero Hour and `Generals/Code` for the original
Generals. Compare the corresponding function's behavior, callers, types and class
layout with the Battle for Middle-earth II reference build. These are different
games on an older branch of the engine. Treat a name or body as evidence only
where the code corresponds. The reference directory is never compiled into
this build. Keep the attribution in [NOTICE](../NOTICE) when you adapt text.

The source snapshot includes 5,856 files and 79,860,286
bytes, measured from the 2025-02-27 upstream Git tree. It includes source,
headers, text build definitions and shader programs from the two `Code`
directories, plus the upstream licence.
Game runtime directories, binary libraries, executables, art, and other
non-source files were left out. The same tree accounts for the omissions below.
